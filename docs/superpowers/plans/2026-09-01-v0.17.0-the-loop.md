# v0.17.0 "The Loop" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the FCP round-trip and give it eyes — an operator prompts an edit, sees the actual media beside the terminal, pushes into Final Cut Pro, exports, and has the change detected and diffed, without opening a file browser.

**Architecture:** Four new modules under `fcpxml/` (pure logic, individually testable) plus four new MCP tool groups registered through a new `tools/` package seam. Nothing existing is moved. `server.py` gains registration lines only. Every new capability degrades to a named, actionable message when its external dependency is absent.

**Tech Stack:** Python 3.10+, `mcp>=1.3.0` (both 1.x and 2.x), `defusedxml`, stdlib `sqlite3`/`socket`/`fractions`, ffmpeg as an external probed binary, `watchdog` as an optional extra.

**Spec:** `docs/superpowers/specs/2026-09-01-cutting-room-design.md`

## Global Constraints

- **Never use floats for time.** All time math uses `fractions.Fraction` or `TimeValue` integer numerator/denominator pairs. `Timecode._exact_seconds` returns a `Fraction` — use it.
- **Never use stdlib `xml.etree.ElementTree.parse()` or `.fromstring()`.** Import from `fcpxml.safe_xml` (`safe_parse`, `safe_fromstring`).
- **Every subprocess is bounded.** `subprocess.run(..., capture_output=True, timeout=<explicit>)` wrapped in `except (OSError, subprocess.TimeoutExpired)`. Follow `fcpxml/media_intel.py:detect_silence` exactly.
- **Never build a shell string.** ffmpeg is invoked with an argument list. No user value reaches a shell.
- **Missing external tool is never an exception.** Probe with `shutil.which`, return `None` or a named message. Copy the `media_intel` pattern.
- **All handlers return `_text_result(text)`** — the `list[TextContent]` wrapper in `server.py`.
- **Frame rates are rationals.** Never `int(fps)`. Use `fcpxml.rational.rational_fps` and friends.
- **Pre-commit is mandatory:** `ruff check . --exclude docs/` must pass with zero errors and `pytest tests/ -v` must be fully green before any commit.
- **Sandbox roots confine every read and write**, including new cache directories. Route paths through the existing `_validate_filepath` / `_resolve_io_paths` helpers in `server.py`.
- **Cache root is `~/.fcp-mcp/`, created mode 700.**
- Target release: version `0.17.0` in `pyproject.toml`, dated CHANGELOG entry, README refresh, GitHub release.

## Deliberately deferred (do not implement in this plan)

These are named so an executor does not "helpfully" add them:

1. Moving existing handlers out of `server.py`; the operation Protocol extraction; the `Timecode`→`TimeValue` read-path unification. Own plan, after this ships.
2. **Triggering** export through SpliceKit or CommandPost. This plan ships detection and reporting only — their RPC signatures must be verified against a live install before any call is written.
3. `xfade` crossfade compilation. v0.17.0 renders hard cuts and reports every transition as a substitution.
4. Layers 3, 4, 5 (index, streaming, scenes, semantic find, organize, journal, review gate).

```python
# tools/__init__.py
"""New MCP tool groups, registered without touching server.py's dispatch.

Existing handlers stay where they are. This package is the seam new
subsystems land in; migrating the old ones is a separate piece of work.
"""

from typing import Any, Awaitable, Callable

Handler = Callable[[dict], Awaitable[list]]

EXTRA_GROUPS: dict[str, dict[str, Any]] = {}
EXTRA_HANDLERS: dict[str, Handler] = {}


def register_group(name: str, description: str, actions: dict[str, Handler]) -> None:
    """Register a tool group and its action handlers.

    Raises on a duplicate group or action name — a silent overwrite would
    shadow a working tool and produce a bug with no symptom at import time.
    """
    if name in EXTRA_GROUPS:
        raise ValueError(f"tool group already registered: {name}")
    for action in actions:
        if action in EXTRA_HANDLERS:
            raise ValueError(f"tool action already registered: {action}")
    EXTRA_GROUPS[name] = {"description": description, "actions": list(actions)}
    EXTRA_HANDLERS.update(actions)
```

```python
# fcpxml/filtergraph.py
"""Compile a parsed Timeline into an ffmpeg graph description.

Pure — no subprocess, no filesystem access beyond an existence check. The
execution half lives in fcpxml/render.py so the compilation can be asserted
exactly, on any machine, with or without ffmpeg installed.

Time is carried as fractions.Fraction end to end. A preview built on float
seconds drifts against the timeline it claims to represent; at 23.976 the
drift is visible within a minute.
"""

from dataclasses import dataclass
from fractions import Fraction
from pathlib import Path
from typing import Any, Iterable

from fcpxml.media_intel import media_src_to_path


@dataclass(frozen=True)
class Segment:
    """One piece of source media placed on the timeline."""

    source: str
    src_in: Fraction
    src_out: Fraction
    tl_in: Fraction
    lane: int
    label: str
    missing: bool = False

    @property
    def duration(self) -> Fraction:
        return self.src_out - self.src_in


@dataclass(frozen=True)
class FilterGraph:
    segments: tuple[Segment, ...]
    total: Fraction
    substitutions: tuple[str, ...]


def _seconds(tc: Any) -> Fraction:
    """Exact seconds for a Timecode, never a float."""
    if tc is None:
        return Fraction(0)
    exact = getattr(tc, "_exact_seconds", None)
    if exact is not None:
        return Fraction(exact)
    return Fraction(tc.seconds).limit_denominator(1000000)


def _resolve(media_path: str) -> tuple[str, bool]:
    """Return (filesystem path, missing?) for a clip's media reference."""
    if not media_path:
        return "", True
    path = media_src_to_path(media_path)
    return path, not Path(path).is_file()


def _segment_from(item: Any, lane: int) -> Segment:
    start = _seconds(item.start)
    duration = _seconds(item.duration)
    src_in = _seconds(getattr(item, "source_start", None))
    source, missing = _resolve(getattr(item, "media_path", "") or "")
    offset = getattr(item, "offset", None)
    tl_in = _seconds(offset) if offset is not None else start
    return Segment(
        source=source,
        src_in=src_in,
        src_out=src_in + duration,
        tl_in=tl_in,
        lane=lane,
        label=item.name,
        missing=missing,
    )


def compile_timeline(timeline: Any) -> FilterGraph:
    """Build a FilterGraph from a parsed Timeline.

    Spine clips are ordered by timeline position and carry lane 0. Connected
    clips keep their own lane: positive is video above the spine, negative is
    audio below.

    Transitions are NOT compiled in this version. Every one is recorded as a
    substitution so the operator is told the preview shows a hard cut where
    their timeline has a dissolve. A silent substitution would make the
    preview lie, which is worse than not having one.
    """
    spine = sorted(getattr(timeline, "clips", []) or [], key=lambda c: _seconds(c.start))
    segments: list[Segment] = [_segment_from(clip, 0) for clip in spine]

    for connected in getattr(timeline, "connected_clips", []) or []:
        segments.append(_segment_from(connected, connected.lane))

    substitutions = tuple(
        f"{t.name!r} at {float(_seconds(t.start)):.2f}s rendered as a hard cut "
        f"(crossfade compilation is not implemented in this version)"
        for t in (getattr(timeline, "transitions", []) or [])
    )

    total = sum((s.duration for s in segments if s.lane == 0), Fraction(0))
    return FilterGraph(segments=tuple(segments), total=total, substitutions=substitutions)


def graph_to_args(graph: FilterGraph, out_path: str, height: int = 480) -> list[str]:
    """Build the ffmpeg argument list that renders *graph* to *out_path*.

    Argument list, never a shell string: no user-supplied value is ever
    interpreted by a shell.

    This version renders the spine only. Lane compositing needs an overlay
    chain and is deliberately out of scope; lanes are still compiled into the
    graph (and therefore reported), they are simply not drawn yet.
    """
    if height <= 0 or height > 2160:
        raise ValueError(f"height must be between 1 and 2160, got {height}")

    spine = [s for s in graph.segments if s.lane == 0 and not s.missing]
    if not spine:
        raise ValueError("nothing renderable: every spine clip is missing its media")

    args: list[str] = ["ffmpeg", "-hide_banner", "-nostdin", "-y"]
    for seg in spine:
        args += [
            "-ss", str(float(seg.src_in)),
            "-t", str(float(seg.duration)),
            "-i", seg.source,
        ]

    chains = []
    for index in range(len(spine)):
        chains.append(
            f"[{index}:v]scale=-2:{height},setsar=1,fps=24[v{index}]"
        )
    concat_inputs = "".join(f"[v{i}]" for i in range(len(spine)))
    chains.append(f"{concat_inputs}concat=n={len(spine)}:v=1:a=0[vout]")

    args += [
        "-filter_complex", ";".join(chains),
        "-map", "[vout]",
        "-c:v", "libx264", "-preset", "veryfast", "-crf", "28",
        "-pix_fmt", "yuv420p",
        out_path,
    ]
    return args
```

```python
# fcpxml/render.py
"""Execute a compiled filtergraph and verify the artifact.

The verification is the point. A rendered file existing is not evidence the
render is correct — ffmpeg exits 0 having written a near-empty container more
often than anyone expects. Every render reads its own duration back off the
artifact and compares it against the timeline's exact rational.
"""

import logging
import os
import shutil
import subprocess
from fractions import Fraction
from pathlib import Path
from typing import Any, Optional

from fcpxml.filtergraph import compile_timeline, graph_to_args

logger = logging.getLogger(__name__)

RENDER_TIMEOUT_SECONDS = 600
PROBE_TIMEOUT_SECONDS = 60


def cache_dir() -> Path:
    """Private cache root for rendered previews."""
    root = Path(os.path.expanduser("~")) / ".fcp-mcp" / "preview"
    root.mkdir(parents=True, exist_ok=True)
    root.chmod(0o700)
    (root.parent).chmod(0o700)
    return root


def probe_duration(path: str) -> Optional[Fraction]:
    """Actual duration of a media file, or None when it is unreadable."""
    if shutil.which("ffprobe") is None:
        return None
    try:
        result = subprocess.run(
            ["ffprobe", "-v", "error", "-show_entries", "format=duration",
             "-of", "default=noprint_wrappers=1:nokey=1", str(path)],
            capture_output=True, text=True, timeout=PROBE_TIMEOUT_SECONDS,
        )
    except (OSError, subprocess.TimeoutExpired):
        return None
    if result.returncode != 0:
        return None
    raw = result.stdout.strip()
    try:
        return Fraction(raw).limit_denominator(100000)
    except (ValueError, ZeroDivisionError):
        return None


def render_proxy(
    timeline: Any, out_path: Optional[str] = None, height: int = 480
) -> dict:
    """Render a low-resolution proxy of *timeline* and verify its duration.

    Never raises on a missing tool or missing media. Returns a dict with
    ``path`` set to None and ``error`` naming exactly what is absent.
    """
    graph = compile_timeline(timeline)
    skipped = [s.label for s in graph.segments if s.missing]

    if shutil.which("ffmpeg") is None:
        return {
            "path": None, "duration": None, "expected": graph.total,
            "drift": None, "substitutions": graph.substitutions, "skipped": skipped,
            "error": "ffmpeg is not on PATH. Install it (brew install ffmpeg) "
                     "to render previews; every other tool is unaffected.",
        }

    if out_path is None:
        out_path = str(cache_dir() / f"{getattr(timeline, 'name', 'timeline')}_proxy.mp4")

    try:
        args = graph_to_args(graph, out_path, height=height)
    except ValueError as exc:
        return {
            "path": None, "duration": None, "expected": graph.total,
            "drift": None, "substitutions": graph.substitutions, "skipped": skipped,
            "error": str(exc),
        }

    try:
        result = subprocess.run(
            args, capture_output=True, text=True, timeout=RENDER_TIMEOUT_SECONDS
        )
    except (OSError, subprocess.TimeoutExpired):
        logger.warning("ffmpeg proxy render failed for %s", out_path)
        return {
            "path": None, "duration": None, "expected": graph.total,
            "drift": None, "substitutions": graph.substitutions, "skipped": skipped,
            "error": f"ffmpeg did not finish within {RENDER_TIMEOUT_SECONDS}s.",
        }
    if result.returncode != 0:
        tail = (result.stderr or "").strip().splitlines()[-3:]
        return {
            "path": None, "duration": None, "expected": graph.total,
            "drift": None, "substitutions": graph.substitutions, "skipped": skipped,
            "error": "ffmpeg failed: " + " / ".join(tail),
        }

    duration = probe_duration(out_path)
    drift = None if duration is None else duration - graph.total
    return {
        "path": out_path, "duration": duration, "expected": graph.total,
        "drift": drift, "substitutions": graph.substitutions, "skipped": skipped,
        "error": None,
    }


def render_frame(source: str, at: Fraction, out_path: str) -> Optional[str]:
    """Extract a single frame from *source* at *at* seconds."""
    if shutil.which("ffmpeg") is None or not Path(source).is_file():
        return None
    try:
        result = subprocess.run(
            ["ffmpeg", "-hide_banner", "-nostdin", "-y",
             "-ss", str(float(at)), "-i", source,
             "-frames:v", "1", out_path],
            capture_output=True, timeout=PROBE_TIMEOUT_SECONDS,
        )
    except (OSError, subprocess.TimeoutExpired):
        return None
    return out_path if result.returncode == 0 and Path(out_path).is_file() else None
```

```python
# fcpxml/visual.py
"""Filmstrip + waveform over a range of SOURCE media.

fcpxml/preview.py renders coloured blocks from the XML: a picture of what we
wrote, not of what the media looks like. That means an edit is currently
verified by re-parsing our own output, which cannot see a bad cut.

This module reads the media, so a flash-frame fix can be confirmed from an
image. Borrowed from browser-use/video-use, which renders a filmstrip and
waveform at every cut boundary before showing a user anything.
"""

import logging
import shutil
import subprocess
from fractions import Fraction
from pathlib import Path
from typing import Optional

logger = logging.getLogger(__name__)

VISUAL_TIMEOUT_SECONDS = 180


def visual_check(
    source: str,
    start: Fraction,
    end: Fraction,
    out_path: str,
    frames: int = 8,
    width: int = 1200,
) -> Optional[str]:
    """Render a filmstrip above an audio waveform for ``source[start:end]``.

    Returns the written path, or None when ffmpeg or the media is absent.
    Raises ValueError only on caller error (a reversed or absurd range), because
    those values end up in a subprocess argument and are not trusted.
    """
    if end <= start:
        raise ValueError(f"end must be after start (got {start} -> {end})")
    if not (1 <= frames <= 64):
        raise ValueError(f"frames must be between 1 and 64, got {frames}")
    if not (64 <= width <= 4096):
        raise ValueError(f"width must be between 64 and 4096, got {width}")

    if shutil.which("ffmpeg") is None:
        logger.info("ffmpeg not found on PATH; visual check unavailable")
        return None
    if not Path(source).is_file():
        return None

    duration = end - start
    cell = max(1, width // frames)
    strip_h = int(cell * 9 / 16)
    # One frame every duration/frames seconds, tiled into a single row.
    rate = f"{frames}/{float(duration)}"

    filtergraph = (
        f"[0:v]fps={rate},scale={cell}:{strip_h},"
        f"tile={frames}x1[strip];"
        f"[0:a]showwavespic=s={width}x{strip_h}:colors=white[wave];"
        f"[strip][wave]vstack=inputs=2[out]"
    )
    fallback = (
        f"[0:v]fps={rate},scale={cell}:{strip_h},tile={frames}x1[out]"
    )

    for graph in (filtergraph, fallback):
        try:
            result = subprocess.run(
                ["ffmpeg", "-hide_banner", "-nostdin", "-y",
                 "-ss", str(float(start)), "-t", str(float(duration)),
                 "-i", str(source),
                 "-filter_complex", graph,
                 "-map", "[out]", "-frames:v", "1", str(out_path)],
                capture_output=True, timeout=VISUAL_TIMEOUT_SECONDS,
            )
        except (OSError, subprocess.TimeoutExpired):
            logger.warning("visual check failed for %s", source)
            return None
        if result.returncode == 0 and Path(out_path).is_file():
            return str(out_path)
        # First attempt includes the audio waveform; a video-only source has
        # no [0:a] and fails the whole graph. Retry without it rather than
        # reporting "no image" for a perfectly good silent clip.
    return None
```

```python
# tools/preview.py
"""The preview tool group — the loop's eyes.

Handlers import server lazily inside their bodies: server.py imports this
package to register the group, so a module-scope import would be circular.
"""

import subprocess
from fractions import Fraction
from pathlib import Path
from typing import Optional

from fcpxml import filtergraph, render, visual
from fcpxml.preview import render_timeline_html

CMUX_PREVIEW = Path.home() / ".claude" / "hooks" / "cmux-image-preview.mjs"


def _open_beside_terminal(paths: list[str]) -> None:
    """Paint artifacts into a pane next to the terminal.

    A path printed in chat is not showing the operator the thing. Failure
    here is cosmetic and must never fail the tool call.
    """
    if not paths or not CMUX_PREVIEW.is_file():
        return
    try:
        subprocess.run(
            ["node", str(CMUX_PREVIEW), *paths],
            capture_output=True, timeout=30,
        )
    except (OSError, subprocess.TimeoutExpired):
        pass


def _timeline_for(filepath: str):
    import server

    return server._parse_project(filepath)


def _result(text: str):
    import server

    return server._text_result(text)


def _describe(result: dict) -> str:
    lines = []
    if result.get("error"):
        lines.append(f"Preview not rendered: {result['error']}")
    else:
        lines.append(f"Rendered: {result['path']}")
        expected, duration = result.get("expected"), result.get("duration")
        if duration is not None and expected is not None:
            lines.append(
                f"Duration {float(duration):.3f}s against an expected "
                f"{float(expected):.3f}s (drift {float(result['drift']):+.3f}s)"
            )
        else:
            lines.append(
                "Duration could NOT be read back — treat this render as unverified."
            )
    for note in result.get("substitutions") or ():
        lines.append(f"Substituted: {note}")
    if result.get("skipped"):
        lines.append(
            "Skipped (media missing): " + ", ".join(result["skipped"])
        )
    return "\n".join(lines)


async def handle_preview_render(args: dict):
    filepath = args.get("filepath")
    if not filepath:
        return _result("preview_render requires 'filepath'.")
    try:
        project, timeline = _timeline_for(filepath)
    except (ValueError, OSError) as exc:
        return _result(f"Could not read {filepath}: {exc}")
    if timeline is None:
        return _result("No timelines found")

    result = render.render_proxy(
        timeline, out_path=args.get("output_path"), height=int(args.get("height", 480))
    )
    if result.get("path"):
        _open_beside_terminal([result["path"]])
    return _result(_describe(result))


async def handle_preview_sheet(args: dict):
    filepath = args.get("filepath")
    if not filepath:
        return _result("preview_sheet requires 'filepath'.")
    try:
        project, timeline = _timeline_for(filepath)
    except (ValueError, OSError) as exc:
        return _result(f"Could not read {filepath}: {exc}")
    if timeline is None:
        return _result("No timelines found")

    graph = filtergraph.compile_timeline(timeline)
    out_dir = render.cache_dir()
    written, skipped = [], []
    for index, segment in enumerate(s for s in graph.segments if s.lane == 0):
        if segment.missing:
            skipped.append(segment.label)
            continue
        target = str(out_dir / f"sheet_{index:04d}.png")
        # Mid-clip, so a frame is representative rather than a fade-in.
        at = segment.src_in + segment.duration / 2
        if render.render_frame(segment.source, at, target):
            written.append(target)
        else:
            skipped.append(segment.label)

    if written:
        _open_beside_terminal(written)
    lines = [f"Contact sheet: {len(written)} frames, one per spine cut."]
    if skipped:
        lines.append("No frame for: " + ", ".join(skipped))
    for note in graph.substitutions:
        lines.append(f"Substituted: {note}")
    return _result("\n".join(lines))


async def handle_preview_frame(args: dict):

    if not source or at is None:
        return _result("preview_frame requires 'source' and 'at' (seconds).")

        source, Fraction(str(at)).limit_denominator(100000), target

            f"No frame extracted from {source}. Check the file exists and "
            "that ffmpeg is on PATH."
        )

    return _result(f"Frame at {at}s: {written}")

        return _result("preview_check requires 'source', 'start' and 'end' (seconds).")
    target = str(render.cache_dir() / "check.png")

        written = visual.visual_check(

            Fraction(str(end)).limit_denominator(100000),

            frames=int(args.get("frames", 8)),

    if not written:
        return _result(
            f"No visual check produced for {source}. Check the file exists and "
            "that ffmpeg is on PATH."
        )
    _open_beside_terminal([written])
    return _result(
        f"Filmstrip + waveform for {source} [{start}s - {end}s]: {written}\n"
        "This is read from the media, not from the XML."

    filepath = args.get("filepath")

        lines.append(f"{bar:<{width}} {segment.label}{flag}")
    for note in graph.substitutions:
        lines.append(f"Substituted: {note}")
    return _result("\n".join(lines))
```

```python
# fcpxml/watchfolder.py
"""Detect an FCPXML export landing in a directory.

Apple ships a fully scriptable import (odoc + <import-options>) and no
programmatic export, verified unchanged across FCP 11.0 to 12.2. This module
is how one Cmd-E becomes something the server notices, closing the loop
without touching an unofficial surface.

Deliberately stat-based rather than watchdog-based. Polling a directory once
a second costs nothing next to an FCPXML parse, has no dependency, and cannot
miss an event while the observer thread is being set up.
"""

import os
import time
from pathlib import Path
from typing import Optional

WATCH_EXTENSIONS = (".fcpxml", ".fcpxmld")


def default_watch_dir() -> Optional[str]:
    """The configured export destination, or None when unset."""
    value = os.environ.get("FCP_WATCH_DIR", "").strip()
    return value or None


class Watcher:
    """Snapshot a directory, then report what changed since the snapshot."""

    def __init__(self, directory: str):
        self.directory = Path(directory)
        self._snapshot: dict[str, tuple[float, int]] = {}
        self._baselined = False

    def _scan(self) -> dict[str, tuple[float, int]]:
        if not self.directory.is_dir():
            raise ValueError(f"{self.directory} is not a directory")
        found: dict[str, tuple[float, int]] = {}
        for entry in self.directory.iterdir():
            if not entry.name.endswith(WATCH_EXTENSIONS):
                continue
            try:
                stat = entry.stat()
            except OSError:
                continue
            # A .fcpxmld is a directory; its own mtime moves when FCP rewrites
            # its contents, which is the signal we want.
            found[str(entry)] = (stat.st_mtime, stat.st_size)
        return found

    def baseline(self) -> None:
        """Record what is already there so it is not reported as an export."""
        self._snapshot = self._scan()
        self._baselined = True

    def changed(self) -> list[str]:
        """Paths that are new or modified since the last baseline."""
        if not self._baselined:
            self.baseline()
            return []
        current = self._scan()
        return sorted(
            path for path, stamp in current.items()
            if self._snapshot.get(path) != stamp
        )

    def pull(self, timeout: float = 120.0, interval: float = 1.0) -> Optional[str]:
        """Block until an export lands, then return its path.

        Returns None on timeout rather than raising: waiting and not getting an
        export is a normal outcome (the operator got distracted), not a fault.
        """
        if timeout <= 0 or timeout > 3600:
            raise ValueError(f"timeout must be between 0 and 3600s, got {timeout}")
        deadline = time.monotonic() + timeout
        while time.monotonic() < deadline:
            found = self.changed()
            if found:
                self._snapshot = self._scan()
                return found[-1]
            time.sleep(interval)
        return None
```

```python
# fcpxml/bridges.py
"""Detect optional third-party FCP control surfaces on loopback.

SpliceKit (JSON-RPC :9876) and CommandPost (WebSocket :27480) can both close
the export half of the loop. Neither is bundled, vendored, required, or
installed by us — the safety position is that this server never patches or
injects anything, and that position is the product.

DETECTION ONLY. Triggering an export through either surface needs their RPC
signatures verified against a live install; writing a call without that is
inventing an API. That work is deliberately out of this version.
"""

import logging
import socket
from typing import Dict

logger = logging.getLogger(__name__)

BRIDGES: Dict[str, int] = {
    "splicekit": 9876,
    "commandpost": 27480,
}

LOOPBACK = "127.0.0.1"

_CACHE: Dict[str, bool] = {}


def probe(port: int, host: str = LOOPBACK, timeout: float = 0.25) -> bool:
    """True when something accepts a TCP connection on *port*.

    Loopback only, short timeout. A probe failure is never an error — it is
    the expected result, and it means the manual export path.
    """
    if host != LOOPBACK:
        raise ValueError(f"bridge probes are loopback-only, refused: {host}")
    try:
        with socket.create_connection((host, port), timeout=timeout):
            return True
    except OSError:
        return False


def detect(refresh: bool = False) -> Dict[str, bool]:
    """Which bridges are reachable. Cached for the session."""
    if _CACHE and not refresh:
        return dict(_CACHE)
    _CACHE.clear()
    for name, port in BRIDGES.items():
        _CACHE[name] = probe(port=port)
    logger.info("bridge detection: %s", _CACHE)
    return dict(_CACHE)


def describe() -> str:
    """One operator-readable line about the export path in force."""
    found = detect()
    live = [name for name, up in found.items() if up]
    if not live:
        return (
            "No control bridge detected. Export from Final Cut Pro with "
            "File > Export XML (Cmd-E) into the watched folder; watch_pull "
            "will pick it up."
        )
    return (
        f"Detected: {', '.join(sorted(live))}. Automatic export triggering is "
        "not implemented in this version — export with Cmd-E as usual."
    )
```

```python
# tools/watch.py
"""The watch tool group — the loop's return path."""

from pathlib import Path
from typing import Any, Dict

from fcpxml import bridges
from fcpxml.watchfolder import Watcher, default_watch_dir

# Module-level because a watcher must survive between tool calls; the MCP
# server is a single long-lived process and there is exactly one operator.
_STATE: Dict[str, Any] = {}


def _result(text: str):
    import server

    return server._text_result(text)


async def handle_watch_start(args: dict):
    directory = args.get("directory") or default_watch_dir()
    if not directory:
        return _result(
            "watch_start needs a directory. Pass 'directory', or set "
            "FCP_WATCH_DIR to your Final Cut Pro export destination."
        )
    watcher = Watcher(directory)
    try:
        watcher.baseline()
    except ValueError as exc:
        return _result(f"Cannot watch: {exc}")

    _STATE["watcher"] = watcher
    _STATE["directory"] = directory
    _STATE["last"] = None
    return _result(
        f"Watching {directory} for .fcpxml and .fcpxmld exports.\n"
        f"{bridges.describe()}"
    )


async def handle_watch_status(args: dict):
    watcher = _STATE.get("watcher")
    if watcher is None:
        return _result("Not watching. Run watch_start first.")
    lines = [f"Watching {_STATE['directory']}"]
    if _STATE.get("last"):
        lines.append(f"Last export seen: {_STATE['last']}")
    else:
        lines.append("No export seen yet.")
    lines.append(bridges.describe())
    return _result("\n".join(lines))


async def handle_watch_stop(args: dict):
    if _STATE.get("watcher") is None:
        return _result("Not watching.")
    directory = _STATE.get("directory")
    _STATE.clear()
    return _result(f"Stopped watching {directory}.")


async def handle_watch_pull(args: dict):
    watcher = _STATE.get("watcher")
    if watcher is None:
        return _result("Not watching. Run watch_start first.")

    timeout = float(args.get("timeout", 120.0))
    try:
        found = watcher.pull(timeout=timeout)
    except ValueError as exc:
        return _result(str(exc))
    if found is None:
        return _result(
            f"No export in {timeout:.0f}s. In Final Cut Pro: File > Export XML "
            f"(Cmd-E) into {_STATE['directory']}, then run watch_pull again."
        )

    previous = _STATE.get("last")
    _STATE["last"] = found
    lines = [f"Export detected: {found}"]

    if previous and Path(previous).exists() and previous != found:
        from fcpxml.diff import compare_timelines

        try:
            diff = compare_timelines(previous, found)
        except (ValueError, OSError) as exc:
            lines.append(f"Could not diff against {previous}: {exc}")
        else:
            lines.append(f"Diff against {previous}:")
            lines.append(str(diff))
    else:
        lines.append(
            "No previous export to diff against — this one is the baseline."
        )
    return _result("\n".join(lines))


ACTIONS = {
    "watch_start": handle_watch_start,
    "watch_status": handle_watch_status,
    "watch_stop": handle_watch_stop,
    "watch_pull": handle_watch_pull,
}

DESCRIPTION = (
    "Close the round-trip. Watch the Final Cut Pro export folder, detect the "
    "XML the moment it lands, and diff it against the last one seen. Pair "
    "with deliver.push_to_fcp for a full loop."
)
```

```python
# fcpxml/edl.py
"""Author FCPXML from an edl.json cut list.

browser-use/video-use reasons over footage and its pipeline terminates at a
flat mp4. This is the bridge that lets that reasoning finish in Final Cut Pro,
which is the only outcome that works for anyone delivering a project file
rather than a video.

Validation is strict and reports by cut index. An EDL is machine-generated,
so a malformed one is a bug upstream, and a silently-dropped cut is a missing
shot nobody notices until the review.
"""

from fractions import Fraction
from pathlib import Path
from typing import Any


class EDLValidationError(ValueError):
    """The cut list is malformed. The message names the offending cut."""


def _fraction(value: Any, index: int, field: str) -> Fraction:
    try:
        return Fraction(str(value)).limit_denominator(1000000)
    except (ValueError, TypeError, ZeroDivisionError):
        raise EDLValidationError(
            f"cut {index}: {field} is not a number (got {value!r})"
        ) from None


def parse_edl(data: dict) -> list[dict]:
    """Validate and normalize an edl.json payload into ordered cuts."""
    if not isinstance(data, dict) or "cuts" not in data:
        raise EDLValidationError("edl.json must be an object with a 'cuts' list")
    raw = data["cuts"]
    if not isinstance(raw, list) or not raw:
        raise EDLValidationError("edl.json must contain at least one cut")

    cuts: list[dict] = []
    for index, item in enumerate(raw):
        if not isinstance(item, dict):
            raise EDLValidationError(f"cut {index}: expected an object")
        source = item.get("source")
        if not source or not isinstance(source, str):
            raise EDLValidationError(f"cut {index}: missing 'source'")
        src_in = _fraction(item.get("start", 0), index, "start")
        src_out = _fraction(item.get("end", 0), index, "end")
        if src_out <= src_in:
            raise EDLValidationError(
                f"cut {index}: end ({src_out}) must be after start ({src_in})"
            )
        cuts.append({
            "source": source,
            "src_in": src_in,
            "src_out": src_out,
            "label": item.get("label") or Path(source).stem,
        })
    return cuts


def edl_to_fcpxml(
    data: dict, out_path: str, fps: float = 24.0, name: str = "EDL Import"
) -> str:
    """Write an FCPXML timeline from an edl.json payload. Returns *out_path*."""
    cuts = parse_edl(data)
    # rough_cut already owns valid-FCPXML authoring from a source clip list;
    # duplicating that here would create a second writer to keep in sync.
    from fcpxml.rough_cut import build_timeline_fcpxml

    return build_timeline_fcpxml(
        clips=[
            {
                "path": cut["source"],
                "name": cut["label"],
                "source_in": cut["src_in"],
                "duration": cut["src_out"] - cut["src_in"],
            }
            for cut in cuts
        ],
        out_path=out_path,
        fps=fps,
        name=name,
    )
```

**If `fcpxml/rough_cut.py` has no function with that shape**, find the closest one it does have (it generates rough cuts, montages and A/B roll, so an equivalent exists) and adapt this call to it. Do not write a second FCPXML writer.

```python
_AUTOPUSH_OFF = {"", "0", "false", "no", "off"}


def _autopush_enabled() -> bool:
    """Whether every write should also land in the running Final Cut Pro.

    Off by default. Repeated imports accumulate library churn, which is the

def _maybe_autopush(output_path: str) -> str:
    """Push *output_path* into FCP when autopush is on. Returns a report line.

    Never raises. The edit already succeeded and is on disk; a failed push is

    if not _autopush_enabled():

        result = live.push_to_fcp(output_path)
    except (RuntimeError, OSError) as exc:
        return f"\nAutopush: not pushed — {exc}"
    launched = " (launched Final Cut Pro)" if result.get("launched_fcp") else ""
    return f"\nPushed to Final Cut Pro: {result.get('sent', output_path)}{launched}"
```
