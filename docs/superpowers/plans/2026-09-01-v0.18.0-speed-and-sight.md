# v0.18.0 "speed and sight" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The second prompt on a project returns in well under a second, every operation over two seconds streams progress, shot boundaries are a first-class analysis, and a whole multi-take shoot reads as one packed transcript.

**Architecture:** A SQLite cache at `~/.fcp-mcp/index.db` (`fcpxml/index.py`) sits *beside* the analysis functions, never inside them — every caller must produce the same answer with the index deleted or disabled (`FCP_MCP_INDEX=off`), only more slowly. Progress goes through one seam (`fcpxml/progress.py`) that resolves the current MCP request on either SDK via `mcp_compat` and drops silently when there is no token. Scene detection (`fcpxml/scenes.py`) has a PySceneDetect backend under the `scenes` extra and an ffmpeg `select=gt(scene,…)` fallback that needs no extra. `transcript_pack` (`fcpxml/transcript_pack.py`) is pure formatting over transcript dicts. The ElevenLabs Scribe backend lives in `transcribe.py` as an opt-in that states audio leaves the machine.

**Tech Stack:** Python 3.10+, stdlib `sqlite3`, `fractions.Fraction`, mcp 1.x floor + 2.x, ffmpeg/ffprobe (external), `scenedetect>=0.7` (extra), `faster-whisper` (extra), `urllib` for Scribe (no new dep).

**Spec:** `docs/superpowers/specs/2026-09-01-cutting-room-design.md` — Layer 3, Layer 4 (`scenes`, `transcript_pack`, diarization), §5–§8, §10.

## Global Constraints

- Core install stays `mcp` + `defusedxml`; every new capability is an extra or ffmpeg, and degrades to a named message with an install command.
- Time values in the index are integer `num/den` pairs. A float converts at the boundary with `Fraction(x).limit_denominator(1_000_000)`.
- The index is a cache, never a source of truth. Suite must pass with `FCP_MCP_INDEX=off`. Invalidation by `(path, mtime, size)`.
- `~/.fcp-mcp/` mode 700. Tests never touch the real index — `tests/conftest.py` redirects it to a tmp path.
- Every subprocess: argument lists, explicit timeout, bounded output. No shell strings.
- Progress unsupported by the SDK → dropped silently; the operation still completes.
- Network egress only in the opt-in Scribe backend, only when `backend="elevenlabs"` is passed, and the result text says audio left the machine. Never read or echo the key.
- Every guard gets a mutation check named in its test.
- Both SDK suites green: `.venv/bin/python -m pytest -q` (floor) and `/tmp/v2/bin/python -m pytest -q` (2.x). `ruff check . --exclude docs/` clean.
- Commits carry `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
